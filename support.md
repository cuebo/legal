# cuebo 技术支持 / Support

cuebo 是一款可配置模型、能力、插件和 Skill 的 iOS 个人助理。

如果遇到安装、模型配置、同步或能力使用问题，请发送邮件至 [codeloverql@gmail.com](mailto:codeloverql@gmail.com)。请附上设备型号、iOS 版本、App 版本、复现步骤和错误截图；不要发送 API Key、密码或其他凭据。

cuebo is an iOS personal assistant with configurable models, capabilities, plugins, and Skills.

For installation, model setup, sync, or feature support, email [codeloverql@gmail.com](mailto:codeloverql@gmail.com). Include your device model, iOS and app versions, steps to reproduce, and a screenshot if useful. Do not send API keys, passwords, or other credentials.
